# 06. STM32 外设初始化规范

## 1. 通用初始化顺序

外设初始化函数按以下顺序组织：

1. 使能相关外设时钟。
2. 配置 GPIO 模式、输出类型、速度和上下拉。
3. 配置 GPIO 复用映射。
4. 初始化外设结构体和工作参数。
5. 清除遗留状态标志。
6. 配置中断源和 NVIC 优先级。
7. 使能外设中断。
8. 使能外设。
9. 设置安全的初始输出状态。

初始化参数应集中在初始化函数中，避免在主循环中反复改写寄存器。每个初始化函数都应具备明确的调用前提和调用顺序。

## 2. GPIO、USART、CAN 和 TIM

- GPIO 端口、引脚、复用功能、有效电平和外部上下拉必须在模块中明确记录。
- USART 必须明确波特率、字长、停止位、校验方式、收发方向、缓冲区大小和中断用途。
- CAN 必须明确标准帧/扩展帧、ID、波特率、过滤器、FIFO 和接收溢出策略。
- TIM 必须明确计数频率、周期、中断周期、优先级和被驱动的控制任务。
- PWM 必须明确频率、周期、比较值范围、舵机角度映射和安全初始占空比。
- EXTI 必须明确端口映射、触发沿、去抖方式、中断优先级和事件处理方式。

## 3. 软件 I²C 和显示模块

软件 I²C 应将 SCL、SDA、设备地址、时序延时和 ACK 策略定义为具名配置。显示接口应说明行列范围、字符编码、刷新周期和是否允许在中断中调用。
